# perfume-brand-website

A luxury perfume brand website for Indian customers, designed with a premium aesthetic and tailored for e-commerce conversion, product storytelling, and secure Indian payment readiness.

## Tech stack
- Next.js 14
- Tailwind CSS
- TypeScript

## Features included
- Premium homepage and brand experience
- Product listing and product detail pages
- About page, contact page, and checkout flow
- Luxury styling themed for perfume retail
- Razorpay-ready flow messaging for Indian payments
- Responsive layout for mobile and desktop

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Project structure
- `app/` — pages and routing
- `components/` — reusable UI blocks
- `data/` — sample content and products
- `public/` — images and media assets (ready for expansion)

## Notes
This project is a front-end website foundation intended to be extended with real product images, CMS data, payment integration, and full ecommerce backend features.
